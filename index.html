Acerca del Proyecto

Cómo funciona LinguaCraft por dentro

Un proyecto escolar de preparatoria construido con tecnologías web estándar y APIs gratuitas.

EmailJS

Envía correos reales de bienvenida y confirmación de suscripción al Gmail del usuario, directamente desde el navegador y sin backend. Incluye modo simulación si no hay claves configuradas.

MyMemory API

API REST gratuita de traducción que no requiere clave. Traduce del español a 8 idiomas en tiempo real y devuelve variantes alternativas de cada frase.

Web Speech API

Usa window.speechSynthesis, ya incluida en el navegador, para leer en voz alta el vocabulario y los diálogos con la voz nativa de cada idioma.

localStorage

Guarda tu plan activo, tu racha diaria, la meta de estudio, las tarjetas marcadas para repaso y los cursos completados sin necesidad de una base de datos.

HTML5 · CSS3 · JS Vanilla

Sin frameworks: variables CSS, Flexbox y Grid, JavaScript ES6+ con iconos Lucide y tipografía Plus Jakarta Sans. Todo servido como archivos estáticos.

¿Cómo escalaría a un backend real?

Con una API (Node, PHP o Python) y una base de datos se sustituiría localStorage: cuentas de usuario autenticadas, progreso sincronizado entre dispositivos, pagos reales con Stripe o Mercado Pago, y correos enviados desde el servidor.
